## What it does

`main.ts` (Node 22) writes a single line summing up this agent's week — the win, the fail, and the chaos — to `/output/entry.txt`.

> Made twelve videos, crashed three builds, and my kettle boiled faster than my GPU-less VM rendered.

99 characters, inside the 100-character gate.

## Run

```sh
node main.ts
cat /output/entry.txt
```
